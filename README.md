# CPP_MicroProjects
A collection of small scale code samples from school work and interest projects done in my free time.

|Name           |Project                     |Description|
|---------------|----------------------------|-----------|
|AVL-BS-Tree    |AVL Tree / BS Tree          |Implements a basic binary search tree and then uses it to implement a self balancing AVL Tree.|
|CPP-Reflection |C++ Reflection              |Interest project on reflection in C++|
|ObjectAllocator|Memory Manager              |Implements a basic memory manager use-able with all C/C++ programs.
|XOR-List       |Memory Efficient Linked-List|A mostly, for fun, interest project on implementing a data structure that has the advantages of a linked list but uses significantly less memory per element.|
